## 简介
本文件系统性地介绍图表插件在编辑器中的实现与使用方法，涵盖传统Mermaid图表和全新的基于Recharts的可视化图表插件。内容覆盖：
- 图表类型：Mermaid 流程图/时序图/类图/状态图等；七种Recharts图表类型
- 图表视图：渲染、交互、编辑模式
- 语法支持与样式定制：主题切换、错误抑制、基础样式
- 智能代理集成：图表生成、更新、删除的自动化支持
- 导出能力：当前实现以 SVG 渲染为主，可结合导出模块进行扩展
- 使用示例与最佳实践：插入、编辑、性能优化与排错

## 项目结构
图表插件采用"插件化 + 编辑器扩展"的组织方式，现已扩展为双插件架构：
- Mermaid 插件：传统图表渲染，基于Mermaid引擎
- Recharts 插件：现代数据可视化，基于shadcn/ui图表组件
- 插件入口负责注册编辑器扩展，并暴露给插件管理器
- 编辑器扩展定义节点类型、命令与菜单/快捷指令
- 节点视图负责渲染与交互（Mermaid 使用内嵌编辑器 + 实时渲染；Recharts 使用Recharts组件）

## 图表类型详解

### Recharts 支持的七种图表类型
Recharts插件支持以下七种图表类型，每种都有特定的数据结构和配置选项：

#### 1. 柱状图 (Bar Chart)
- **用途**：比较不同类别的数值大小
- **数据结构**：需要categoryKey作为x轴标签，dataKeys作为y轴数值
- **特性**：支持堆叠、水平布局、数据标签

#### 2. 折线图 (Line Chart)
- **用途**：展示趋势变化和连续数据
- **数据结构**：支持平滑曲线和直线两种类型
- **特性**：可配置点标记、线条粗细、数据标签

#### 3. 面积图 (Area Chart)
- **用途**：展示趋势和累积量
- **数据结构**：与折线图类似，但填充区域
- **特性**：支持堆叠面积图、透明度控制

#### 4. 饼图 (Pie Chart)
- **用途**：展示比例分布和构成
- **数据结构**：单个dataKey用于数值，categoryKey用于标签
- **特性**：支持环形图(innerRadius)、自定义颜色

#### 5. 雷达图 (Radar Chart)
- **用途**：多维度数据对比
- **数据结构**：多个dataKeys表示不同维度
- **特性**：极坐标网格、多系列对比

#### 6. 径向条形图 (Radial Bar Chart)
- **用途**：展示进度和完成度
- **数据结构**：单个dataKey表示百分比
- **特性**：圆形背景、圆角设计

#### 7. 散点图 (Scatter Chart)
- **用途**：展示两个变量之间的关系
- **数据结构**：需要至少两个dataKeys表示x和y坐标
- **特性**：支持第三个维度(ZAxis)表示大小

## 性能考虑
- Mermaid 视图
  - 防抖：对编辑器输入进行 500ms 防抖，降低解析与渲染频率
  - 主题切换：仅在主题变化时重新初始化引擎，避免重复初始化
  - 渲染缓存：将 SVG 以 Base64 data URI 存储，减少重复渲染开销
  - 错误抑制：关闭错误渲染，避免异常语法导致 UI 抖动
- Recharts 视图
  - 组件缓存：使用useMemo缓存图表配置和数据
  - 条件渲染：空数据时显示占位符而非渲染图表
  - 主题适配：通过CSS变量支持明暗主题切换
  - 响应式设计：使用ResponsiveContainer自动适应容器尺寸
- Canvas 思维导图
  - 设备像素比：根据设备像素比设置画布尺寸，保证清晰度
  - 重绘范围：仅在节点集合或容器尺寸变化时重绘
  - 交互操作：通过命中检测定位节点，批量更新数据模型后一次性重绘

## 故障排查指南
- Mermaid 无预览
  - 检查是否提供有效源码；确认 parse 校验通过后再渲染
  - 确认主题切换后已重新初始化引擎
  - 若出现语法错误，当前实现会抑制错误渲染，请检查源码
- Recharts 图表不显示
  - 检查图表配置是否正确：type、data、dataKeys、categoryKey
  - 确认数据格式符合要求：data必须是非空数组
  - 验证数据键名是否存在：确保dataKeys在数据对象中存在
  - 检查图表类型兼容性：某些配置仅适用于特定图表类型
- 视图空白或未更新
  - 确认节点属性 data 已更新
  - 检查防抖时间是否过长导致延迟
- 思维导图画布不显示
  - 检查容器尺寸计算与 Canvas 尺寸设置
  - 确认节点数组存在且包含根节点
- 插件未生效
  - 确认插件已安装并被插件管理器加载
  - 如从市场安装，确认安装流程完成并触发了刷新事件
- 智能代理问题
  - 检查图表技能是否正确注册
  - 验证工具调用参数格式是否正确
  - 确认图表模板是否可访问

### 使用示例与最佳实践
- 插入 Mermaid 图表
  - 在编辑器中输入"/mermaid"，选择对应条目，即可插入空节点
  - 在右侧编辑器中编写 Mermaid 源码，实时预览
- 插入 Recharts 图表
  - 在编辑器中输入"/chart"，选择对应条目，即可插入图表节点
  - 使用智能代理技能或工具集自动创建图表
  - 参考内置模板快速开始
- 插入思维导图
  - 在编辑器中输入"/mindmap"，选择对应条目，即可插入默认思维导图
  - 点击画布选择节点，使用工具栏添加子节点/兄弟节点、删除节点、重置布局
- 语法与样式建议
  - Mermaid：优先使用官方语法，合理分组与注释；在深色/浅色主题间切换时保持一致性
  - Recharts：使用标准数据结构，合理选择图表类型；利用模板系统快速上手
  - 思维导图：控制节点数量，避免过度密集；必要时调整容器尺寸
- 智能代理最佳实践
  - 使用getChartTemplates获取示例配置
  - 通过listCharts了解文档中现有图表
  - 使用updateChart进行增量修改
- 导出建议
  - 当前以 SVG 渲染为主，可结合导出模块将 SVG 转换为 PNG 或 PDF
- 性能优化
  - 对频繁编辑的图表启用较长防抖间隔
  - 大型思维导图尽量减少重绘次数，批量更新数据模型后再渲染
  - Recharts图表使用useMemo缓存配置，避免不必要的重新渲染
