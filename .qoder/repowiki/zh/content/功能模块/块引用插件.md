## 简介

块引用插件是 Knowledge 编辑器的一个功能模块，提供页面和块引用功能。该插件允许用户在文档中创建指向其他页面或特定块的链接引用，支持智能搜索、悬停预览、缓存优化等特性。

主要功能包括：
- **块引用** - 引用来自任何页面的特定块
- **页面引用** - 链接到页面并自动解析标题
- **智能搜索** - 跨空间和页面的防抖搜索
- **悬停预览** - 悬停时预览引用内容
- **高性能优化** - 使用 React.memo 和缓存机制

## 核心组件

### 插件入口点

插件通过 `BlockReferencePlugin` 类实现，继承自 `KPlugin` 基类，提供配置接口和编辑器扩展。

### 扩展系统

插件使用 Tiptap 扩展系统，通过 `ExtensionWrapper` 接口注册多个扩展：
- `PageReference` - 页面引用节点
- `BlockReference` - 块引用节点
- Slash 命令集成

### 数据获取钩子

提供三个核心自定义钩子：
- `useBlockInfo` - 获取块信息并带缓存
- `usePageInfo` - 获取页面信息并带缓存
- `useSpaceService` - 访问空间服务

## 性能考虑

### 优化策略

1. **React.memo 包装** - 所有组件都使用 `React.memo` 进行优化
2. **缓存机制** - LRU 缓存系统减少重复请求
3. **防抖搜索** - 500ms 防抖延迟减少 API 调用
4. **内存管理** - 正确的事件监听器清理防止内存泄漏
5. **懒加载** - 内容解析和编辑器初始化按需进行

### 性能指标

根据优化报告，插件实现了以下性能改进：
- **60% 减少不必要的重新渲染**
- **95% 类型安全性** 
- **零运行时类型错误**
- **40% 更快的块引用初始加载**

## 故障排除指南

### 常见问题

1. **页面引用显示为"页面已删除"**
   - 检查页面是否仍然存在
   - 验证缓存是否过期
   - 查看网络连接状态

2. **块引用无法加载内容**
   - 确认块 ID 是否正确
   - 检查块是否被删除或移动
   - 尝试刷新缓存

3. **搜索功能无响应**
   - 检查防抖设置 (500ms)
   - 验证 SpaceService 是否正常工作
   - 确认网络连接稳定

### 调试技巧

1. **启用开发模式** - 查看控制台中的错误信息
2. **检查缓存状态** - 使用 `clearAllCaches()` 清理缓存
3. **验证服务连接** - 确认 `useSpaceService()` 返回有效实例
