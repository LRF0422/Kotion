## 简介
本文件管理插件为编辑器提供"文件夹管理、附件上传、图片管理与文件浏览"能力，并通过编辑器扩展将"文件卡片组件、文件列表组件、文件上下文管理"整合到编辑器工作流中。插件以 KPlugin 为基础，注册菜单入口、路由视图以及编辑器扩展（文件夹节点、附件节点、图片节点）。**重大更新**：插件现在提供FileServiceImpl实现，支持完整的文件管理功能，替代了旧的useUploadFile钩子，通过统一的useFileService钩子提供服务访问。

**重大改进**：本次更新新增了FileServiceImpl实现、FileSelectorService单例服务、服务注册系统、统一文件服务接口，显著提升了文件管理的完整性和可扩展性。**新增**：FileList组件经过React.memo优化，FileContext增强状态管理，FileManagerView实现移动端响应式设计，为后续拖拽功能奠定基础。**重要更新**：文件管理器组件现已集成全局超时机制，通过50秒的HTTP请求超时配置和完善的错误处理，显著改善了用户体验。

## 项目结构
文件管理插件位于 packages/plugin-file-manager，主要分为四大部分：
- 插件入口与注册：定义插件类、菜单、路由与编辑器扩展，注册FileService服务。
- 编辑器扩展：文件夹节点、附件节点、图片节点及其视图。
- 组件与上下文：文件管理界面、文件卡片、文件列表、上下文状态。
- 对话框与工具：创建文件夹、重命名、移动、文件详情等专用对话框，以及AI操作工具。

## 核心组件
- 插件入口与注册
  - 通过 KPlugin 创建插件实例，注册编辑器扩展（文件夹、图片）、路由视图（文件管理页面）与菜单入口。
  - **新增**：通过getFileService()创建FileService实例并注册到插件服务系统中。
- 文件管理视图（FileManagerView）
  - 提供树形导航、文件卡片网格、工具栏、选择模式与确认回调。
  - 内置上传、删除、下载、列表切换等交互。
  - **新增**：面包屑导航、文件夹对话框、上下文菜单。
  - **更新**：使用useFileService钩子替代旧的useUploadFile钩子。
  - **新增**：移动端响应式设计，支持移动端菜单抽屉。
  - **新增**：视图模式切换（网格/列表）。
  - **新增**：集成全局超时机制，提供50秒的HTTP请求超时保护。
- 文件卡片与列表
  - FileCard：单个文件/文件夹卡片，支持勾选、双击进入、右键选择、操作按钮。
  - **更新**：FileCard和FileCardList使用React.memo优化，提升渲染性能。
  - FileList：**新增** FileListView组件，使用现代化的上下文驱动文件列表系统。
  - **新增**：FileListRow组件，使用React.memo优化单行渲染。
- 文件上下文（FileManageContext）
  - 暴露当前文件夹、已选文件、选择状态更新、上传/删除处理等方法。
  - **增强**：新增loading和error状态管理，提供更好的错误处理。
  - **增强**：新增视图模式管理（grid/list）。
  - **增强**：新增面包屑导航路径和历史记录管理。
  - **增强**：新增文件重命名、移动、复制、复制等操作方法。
- 编辑器扩展
  - 文件夹节点：插入文件夹块，支持属性（folderId），可弹出文件管理器选择目录。
  - 附件节点：作为块级节点承载附件信息，支持内联和块级两种显示模式。
  - 图片节点：支持输入规则、命令插入、尺寸调整与对齐布局。
- **新增**：AI操作工具
  - 提供网络图片插入等AI代理可以直接使用的工具函数。
- **新增**：FileService接口
  - 统一的文件操作接口，支持上传、下载、删除、重命名、移动等操作。
  - 通过插件服务系统注册和访问。
- **新增**：FileSelectorService单例服务
  - 提供统一的文件选择器服务接口，支持Promise式回调。
  - 管理DOM容器和组件生命周期，避免内存泄漏。
  - 支持多实例隔离和测试环境清理。
- **新增**：拖拽功能规划
  - 计划实现拖拽文件上传功能，提升用户体验。
  - 与现有文件管理功能无缝集成。
- **新增**：超时机制
  - 全局HTTP请求超时配置（50秒），防止长时间无响应。
  - 完善的超时错误处理和用户反馈机制。
  - Toast通知系统提供即时的错误提示。

## 架构总览
文件管理插件采用"编辑器扩展 + 页面视图 + 上下文状态 + 专用对话框 + 文件服务 + 超时机制"的分层设计：
- 编辑器扩展层：负责在编辑器中插入/渲染文件夹、附件、图片节点。
- 视图层：文件管理页面提供树形导航与卡片网格浏览；文件夹节点视图提供选择与预览。
- 数据层：通过统一 API 访问后端，实现根目录、子目录、上传与创建等操作。
- **新增**：文件服务层：FileServiceImpl提供统一的文件操作接口，替代旧的useUploadFile钩子。
- **新增**：文件选择器服务层：FileSelectorService提供单例文件选择器服务，管理DOM容器和生命周期。
- **新增**：服务注册层：通过插件服务系统注册和访问FileService。
- **新增**：对话框层：提供创建文件夹、重命名、移动、文件详情等专用对话框。
- **新增**：工具层：提供AI代理可以直接使用的文件操作工具。
- **新增**：性能优化层：React.memo优化、useMemo缓存、useCallback稳定回调。
- **新增**：响应式设计层：移动端适配、抽屉菜单、视图模式切换。
- **新增**：超时保护层：全局HTTP请求超时配置（50秒），完善的错误处理和用户反馈机制。

### 超时机制详解
- **新增**：全局HTTP请求超时配置
  - 在packages/core/src/utils/request.tsx中配置了50秒的HTTP请求超时。
  - 该配置适用于所有API调用，包括文件管理器的所有操作。
- **新增**：超时错误处理机制
  - 当请求超过50秒时，自动触发超时错误处理。
  - 错误消息被本地化为"系统接口请求超时"。
  - 通过Toast通知系统向用户显示错误信息。
- **新增**：用户反馈机制
  - 超时错误通过Toast通知系统显示，位置为顶部右侧。
  - 错误通知持续时间为2秒，确保用户能够及时看到。
  - 用户可以点击重试按钮重新发起操作。
- **新增**：集成方式
  - 所有文件管理器组件和API调用都受益于超时机制。
  - FileService、FileSelectorService等服务也自动获得超时保护。
  - 确保了整个文件管理系统的可靠性和用户体验。

## 故障排查指南
- 无法加载目录
  - 检查 GET_ROOT_FOLDER 与 GET_CHILDREN 的返回结构是否符合预期（需包含 id、name、type、children 等字段）。
  - 确认 currentFolderId 与 folderId 参数传递正确。
  - **新增**：检查是否出现超时错误（系统接口请求超时）。
- 上传失败
  - 确认 UPLOAD_FILE 与 CREATE_FOLDER 的 URL 与方法配置正确。
  - 检查 FileService.upload() 返回的路径与原始名是否可用。
  - **新增**：检查FileService实例是否正确注册到插件服务系统。
  - **新增**：检查超时机制是否正常工作（50秒超时配置）。
- 文件夹节点不显示内容
  - 确认 folderId 是否已设置；未设置时需通过弹窗选择目录并更新属性。
  - **新增**：检查节点操作是否受到超时机制影响。
- 权限与访问
  - 若访问路径异常，检查 FileService.getDownloadUrl() 生成的服务端路径是否正确。

## 结论
文件管理插件通过清晰的分层设计，将编辑器扩展与页面视图有机结合，提供了完整的文件夹管理、附件上传与图片管理能力。**重大更新**：插件现在提供FileServiceImpl实现，通过统一的FileService接口替代了旧的useUploadFile钩子，实现了完整的文件管理功能。新增的服务注册系统使得文件操作更加标准化和可扩展。**新增**：FileSelectorService单例服务的引入，提供了统一的文件选择器接口，支持Promise式回调和DOM容器管理，显著提升了文件选择的用户体验和代码质量。**新增**：FileList组件经过React.memo优化，FileContext增强状态管理，FileManagerView实现移动端响应式设计，为后续拖拽功能奠定基础。**重要更新**：文件管理器组件现已集成全局超时机制，通过50秒的HTTP请求超时配置和完善的错误处理，显著改善了用户体验。这一超时机制确保了所有文件管理操作的可靠性和响应性，防止长时间无响应导致的用户体验问题。本次更新显著提升了用户体验和操作效率，同时增强了系统的可维护性和可扩展性。后续可在性能、权限与交互细节上持续优化，特别是拖拽功能的实现。
